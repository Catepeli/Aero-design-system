# Aero-design-system
Design System production-ready pour industrie aéro.

Design System production-ready pour industrie aéronautique & métrologie. Tokens-first, composants accessibles (WCAG AAA), démo interactive.
{WIP} Ce repository partage un projet en cours de réalisation, afin de constituer une carte des processus de construction d'un modèle de design system modulable pour l'IA.
Pourquoi ce DS?

Les interfaces critiques en aéronautique exigent précision, fiabilité, accessibilité. Ce système garantit:

(en cible)

    ✅ Cohérence visuelle : tokens centralisés, appliqués partout
    ✅ Accessibilité vraie : WCAG AA (4.5:1 contraste), keyboard nav, screen reader ready
    ✅ Scalabilité : 25 composants core, extensible
    ✅ Maintenabilité : source unique (JSON) → multi-output (SASS, CSS, JSON)
    ✅ Performance : CSS minimal, pas de runtime dépendances
